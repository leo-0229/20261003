# 도덕링고

index.html을 브라우저에서 열면 실행됩니다. 설치나 인터넷 연결이 필요 없습니다.

보왕삼매론 10개 항목, 주자십회 10개 항목, 겸손의 기도문 4개 부분을 수록했습니다.

- 읽기 → 빈칸 연습 → 안 보고 쓰기로 부분별 암기
- 빈칸은 항목별 핵심 내용을 1번/2번 연습으로 나누어 보여 주고, 초성 힌트는 켜고 끌 수 있습니다.
- 첫 글자 힌트, 원문 펼치기, 틀린 글자 비교
- 선택한 글의 전체 백지 쓰기 (번호 포함, 제목 생략)
- 암기 완료 표시, 답안 자동 저장, 저장 데이터 삭제

비교는 공백과 문장부호를 제외한 글자의 편집 거리로 계산합니다. 주황색은 빠졌거나 다른 원문 글자, 취소선은 추가되거나 다르게 쓴 글자입니다. 진도와 부분별/전체 답안은 브라우저 localStorage에 저장됩니다. 외부 전송은 없습니다. 빈칸 답안은 저장되지 않습니다. 브라우저 설정에 따라 로컬 파일의 저장이 제한될 수 있습니다.

마지막에는 실제 종이에 써 보세요.
